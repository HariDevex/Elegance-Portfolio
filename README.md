## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/elegancedev/elegance-it-geo-infotech.git
cd elegance-it-geo-infotech
npm install
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```
